# 페이지 작성: 세부 사항

## 경로 규칙 {#path-rules}

VitePress는 `akariContent`가 생성한 `rewrites` 함수로 각 페이지를 어디에서 제공할지 정합니다.

| 소스 파일 | 제공 위치 | 경로 |
| --- | --- | --- |
| `en-US/index.md` | `index.md` | `/` |
| `en-US/theme/layout/index.md` | `theme/layout.md` | `/theme/layout.html` |
| `en-US/styles/icons/using.md` | `styles/icons/using.md` | `/styles/icons/using.html` |
| `zh-CN/index.md` | `zh-CN/index.md` | `/zh-CN/` |
| `zh-CN/theme/i18n/index.md` | `zh-CN/theme/i18n.md` | `/zh-CN/theme/i18n.html` |
| `404.md`(언어 폴더 밖) | 변경 없음 | 변경 없음 |

- 루트 언어의 폴더 이름은 경로에서 빠집니다. 다른 언어는 폴더 이름을 접두사로 유지합니다.
- 정확히 “언어/카테고리/글/index.md” 위치에 있는 파일은 “카테고리/글.md”로 재작성되므로, 글의 경로는 폴더 이름이 되고 끝에 슬래시가 붙지 않습니다. 다른 파일은 루트 언어의 폴더 이름만 빠집니다.
- 이 사이트의 루트 언어는 영어이고 `cleanUrls`는 꺼져 있습니다. 경로가 `.html`로 끝나며 빌드 출력의 파일과 일대일로 대응합니다. `cleanUrls`를 켜면 경로에 확장자가 없으며, `/theme/layout`은 여전히 `theme/layout.html` 파일에 대응합니다.

## 상대 경로

- **링크**: VitePress는 Markdown 링크에 `.html`만 붙여 출력하고(`cleanUrls`가 꺼져 있을 때), 브라우저는 페이지 경로를 기준으로 링크를 해석합니다. 글의 경로는 `/theme/layout.html`이므로, 그 안의 `./sidebar`는 글 폴더 안의 파일이 아니라 `/theme/sidebar.html`을 가리킵니다. 그러니 내부 링크는 전체 경로로 작성하세요.
- **이미지와 자산**: Vite는 이미지를 모듈로 가져오고 소스 파일의 위치를 기준으로 해석하므로, `./image.png`는 글 폴더 안의 파일을 가리킵니다. 작은 이미지는 data URL로 인라인되고, 나머지는 빌드할 때 해시가 붙어 출력으로 복사됩니다.

## 내비게이션 생성 방식

각 언어의 내비게이션은 언어 폴더에서 다음 규칙에 따라 생성됩니다.

- **카테고리**: 언어 폴더 안의 각 폴더가 카테고리입니다. 순서는 공통 구성의 `sidebar.categories` 키 순서, 그다음 언어 구성에만 있는 키, 그다음 `categories`에 없는 폴더를 이름순으로 따릅니다. 글이 없는 카테고리는 표시되지 않습니다. 카테고리의 이름은 `text`이며, 없으면 폴더 이름입니다.
- **글**: 카테고리 폴더 안에서 `index.md`가 있는 각 폴더입니다. 이름은 프런트매터의 `title`, 그다음 첫 번째 h1 제목, 그다음 폴더 이름 순으로 정해집니다. 정렬은 먼저 `order`를 비교합니다. `order`가 없는 글은 맨 뒤로 가고, 같은 값은 폴더 이름순으로 정렬됩니다.
- **홈 페이지**: 언어 폴더의 `index.md`는 기본적으로 내비게이션에 없습니다. `category`를 지정하면 그 카테고리에 들어가고, `order`가 없으면 카테고리의 맨 앞에 옵니다.
- **병렬 페이지**: `parallel`의 각 항목이 순서대로 탭 하나가 되고, 글 자체가 첫 번째 탭입니다. 내비게이션의 항목에는 자체 링크가 없으며, 첫 번째 탭이 그 역할을 합니다. 병렬 페이지는 내비게이션에 따로 나타나지 않습니다.
- **h1 제목 찾기**: 펜스 코드 블록은 건너뛰고, `# `로 시작하는 첫 줄을 가져와 Markdown 마크업을 제거합니다.

생성된 내비게이션은 직접 작성한 `sidebar.items`(`AkariSidebarItem`)와 구조가 같으므로, 펼치기, 강조, 페이지 이동, 푸터의 링크 열이 모두 똑같이 동작합니다.

## 알림

내비게이션을 생성하는 동안 다음 경우에 터미널에 알림이 표시됩니다. 각 알림은 한 번만 나타납니다.

- `parallel`에 나열된 파일이 없거나, 글 폴더 안의 파일 이름이 아닌 경우(예: 경로를 적은 경우). 해당 항목은 건너뜁니다.
- 페이지가 내비게이션 구조에 속하지 않는 경우: 카테고리 폴더에 바로 놓인 `.md`, 더 깊이 중첩된 파일, 어떤 글도 병렬 페이지로 나열하지 않은 파일. 이런 파일도 페이지는 되지만 내비게이션에 나타나지 않을 뿐입니다.
- `rootLanguage`가 지정한 폴더가 언어 폴더가 아닌 경우.

## 대응 페이지

언어를 바꾸면 테마는 현재 경로를 대상 언어의 경로로 옮깁니다(`/theme/i18n.html` ↔ `/zh-CN/theme/i18n.html`). 대상 언어의 내비게이션에 그 경로가 있으면 그 페이지를 열고, 없으면 대상 언어의 홈 페이지를 엽니다. 따라서 두 페이지가 각 언어 폴더에서 같은 경로에 있고, 대상 페이지가 대상 언어의 내비게이션에 포함되어 있을 때 언어를 바꿔도 같은 페이지에 머뭅니다.

## 검색 색인

VitePress가 로컬 검색 색인을 만들므로, 그 링크는 페이지의 실제 경로입니다(위의 재작성을 거친 뒤의 경로). 색인은 언어마다 하나씩 있습니다. 각 페이지는 제목에서 섹션으로 나뉘며, 1단계 제목 아래 부분이 페이지 자체를 나타내고, 병렬 페이지는 각각 독립된 페이지입니다.
