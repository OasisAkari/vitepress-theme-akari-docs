# 레이아웃과 앱 바

레이아웃은 [m3.material.io](https://m3.material.io)와 같습니다. 앱 바와 사이드 내비게이션은 창에 고정되고, 콘텐츠, 오른쪽 목차, 페이지 이동 카드는 둥근 문서 표면 하나 위에 놓입니다. 푸터는 그 아래의 두 번째 표면입니다. 브라우저 창이 페이지 전체를 스크롤하므로, 페이지 내 찾기, 뒤로·앞으로 이동, 앵커 이동이 모두 브라우저의 평소 방식대로 동작합니다.

## 앱 바

- **왼쪽**: 사이트 로고, 이름, 버전 번호. 글 제목이 앱 바 아래로 스크롤되면 이름이 현재 페이지의 제목으로 바뀝니다. 좁은 화면에서는 내비게이션 드로어를 여는 메뉴 버튼이 맨 왼쪽에 나타납니다.
- **오른쪽**: 검색 상자, 소셜 링크, 설정 버튼. 공간이 부족하면 검색 상자는 원형 버튼으로 줄어들고, 소셜 링크와 설정은 점 세 개 모양의 “더보기” 메뉴로 들어갑니다.

앱 바의 내용은 `appBar` 구성에서 설정합니다.

```ts
appBar: {
  title: "Vitepress Theme Akari Docs",
  version: "v1.0.0",
  socialLinks: [
    { icon: "github", link: "https://github.com/OasisAkari/vitepress-theme-akari-docs", label: "GitHub" },
  ],
},
```

## 문서 표면과 목차

- 단락과 목록은 너비가 최대 약 760px입니다. 제목, 표, 코드 블록은 표면의 전체 너비를 차지합니다.
- 오른쪽 목차는 2단계와 3단계 제목을 나열합니다. 읽는 동안 현재 섹션을 강조하고, 제목을 클릭하면 그 제목까지 부드럽게 스크롤합니다.
- 창 너비가 960px보다 좁으면 목차가 숨겨지고, 대신 오른쪽 아래의 목차 버튼으로 엽니다.
- 페이지의 프런트매터에 `toc: false`를 쓰면 그 페이지에는 목차가 없습니다.

병렬 페이지 그룹에 속한 페이지는 표면 상단에 탭 바가 있습니다. [사이드 내비게이션](/ko-KR/theme/sidebar#parallel-pages)을 참고하세요. 히어로가 있는 페이지는 표면 상단에 제목과 이미지가 표시됩니다. [히어로](/ko-KR/theme/hero)를 참고하세요.

## 플로팅 액션 버튼

- **맨 위로**: 페이지를 스크롤하면 오른쪽 아래에 나타납니다. 클릭하면 맨 위까지 부드럽게 스크롤하며, 이동하는 동안 펼쳐져 “맨 위로”를 표시합니다. 다시 클릭하거나 직접 스크롤하면 멈춥니다.
- **목차**: 창 너비가 960px보다 좁으면 그 위에 나타납니다. 클릭하면 현재 페이지의 목차가 담긴 패널로 펼쳐지고, 패널 바깥을 클릭하면 닫힙니다.

## 푸터

페이지 이동 카드 다음에 물결 구분선과 푸터가 옵니다. 왼쪽에는 로고, 사이트 이름, `footer.message`가, 오른쪽에는 링크 열이, 하단에는 `footer.copyright`가 있습니다. 기본적으로 링크 열은 내비게이션의 처음 네 카테고리를 가져옵니다.

## 로딩 바

페이지를 불러오는 동안에는 기본 색상의 얇은 막대가 창 맨 위를 따라 진행됩니다. 사이트를 처음 열 때는 스크립트, 이미지, 글꼴을 기다리고, 사이트 안에서 이동할 때는 다음 페이지의 스크립트와 그 이미지, 글꼴을 기다립니다. 금방 끝나는 로드에서는 아무것도 표시되지 않습니다. 구성에서 끌 수 있습니다. [API](/ko-KR/theme/layout/api#loadingbar)를 참고하세요.

## 창 크기

| 창 너비 | 내비게이션 | 목차 |
| --- | --- | --- |
| 1600px 이상 | 레일과 내비게이션 드로어가 모두 항상 표시됨 | 오른쪽 |
| 960–1599px | 레일. 포인터가 카테고리 위에 머물면 내비게이션 드로어가 미끄러져 나옴 | 오른쪽 |
| 960px 미만 | 앱 바의 메뉴 버튼이 내비게이션 드로어를 엶 | 오른쪽 아래의 버튼 |
| 600px 미만 | 위와 같음. 문서 표면이 창 가장자리까지 닿음 | 오른쪽 아래의 버튼 |

모든 옵션, CSS 변수, 페이지 상태는 [API](/ko-KR/theme/layout/api)를, 스크롤, 제목 전환, 버튼 접기 등의 동작 방식은 [세부 사항](/ko-KR/theme/layout/details)을 참고하세요.
