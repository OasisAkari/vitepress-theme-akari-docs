# 검색

검색은 앱 바 오른쪽에 있습니다. 넓은 화면에서는 자리표시자 텍스트와 단축키 힌트가 있는 검색 상자이고, 좁은 화면에서는 원형 버튼으로 줄어듭니다. 클릭하거나 `⌘K`(Windows와 Linux에서는 `Ctrl K`)를 누르면 검색 상자가 검색 패널로 펼쳐집니다.

## 사용법

| 키 | 동작 |
| --- | --- |
| `⌘K` / `Ctrl K` | 어느 페이지에서나 검색 열기 |
| `↑` / `↓` | 결과 사이 이동 |
| `Enter` | 현재 결과 열기 |
| `Esc` | 검색 닫기 |

결과는 페이지와 섹션별로 나열되며, 각각 일치 부분의 발췌문이 함께 표시됩니다. 섹션 결과를 열면 해당 제목으로 스크롤됩니다. 다국어 사이트에서는 현재 언어의 페이지만 반환됩니다.

## 로컬 색인

기본적으로 백엔드가 필요 없습니다. 테마는 VitePress의 로컬 검색이 만드는 색인을 씁니다. 언어마다 하나씩 있으며, 해당 언어에서 처음 검색할 때만 내려받습니다. 페이지는 제목을 기준으로 섹션으로 나뉘고, 일치 여부는 [MiniSearch](https://lucaong.github.io/minisearch/)가 판단합니다. 중국어와 일본어는 단어로 나뉘고, 단어는 일부만 입력해도 되며, 긴 단어는 한두 글자 틀려도 일치할 수 있습니다. 개발 서버가 실행되는 동안에는 색인이 수정 내용을 따라갑니다.

## 다른 검색 사용

의미 검색이나 사이트 외부의 콘텐츠가 필요하면 HTTP 엔드포인트나 직접 작성한 JS 함수로 전환합니다.

```ts
// docs/config.ts
search: {
  backend: { type: "http", endpoint: "/api/docs/search" },
},
```

백엔드 작성 방법과 결과 형식은 [API](/ko-KR/theme/search/api)를, 패널의 모션과 색인 빌드·순위 결정 방식은 [세부 사항](/ko-KR/theme/search/details)을 참고하세요.
