# ページの作成：詳細

## パスのルール {#path-rules}

VitePress は、`akariContent` が生成する `rewrites` 関数で各ページの配信場所を決めます。

| ソースファイル | 配信時のファイル | パス |
| --- | --- | --- |
| `en-US/index.md` | `index.md` | `/` |
| `en-US/theme/layout/index.md` | `theme/layout.md` | `/theme/layout.html` |
| `en-US/styles/icons/using.md` | `styles/icons/using.md` | `/styles/icons/using.html` |
| `zh-CN/index.md` | `zh-CN/index.md` | `/zh-CN/` |
| `zh-CN/theme/i18n/index.md` | `zh-CN/theme/i18n.md` | `/zh-CN/theme/i18n.html` |
| `404.md`（言語フォルダーの外） | 変更なし | 変更なし |

- ルート言語のフォルダー名はパスから取り除かれます。ほかの言語はフォルダー名を接頭辞として残します。
- ちょうど「言語/カテゴリ/記事/index.md」の位置にあるファイルは「カテゴリ/記事.md」に書き換えられます。そのため、記事のパスはフォルダー名になり、末尾にスラッシュは付きません。それ以外のファイルは、ルート言語のフォルダー名が取り除かれるだけです。
- このサイトのルート言語は英語で、`cleanUrls` は無効です。パスは `.html` で終わり、ビルド結果のファイルと 1 対 1 で対応します。`cleanUrls` を有効にするとパスに拡張子が付かず、`/theme/layout` は引き続きファイル `theme/layout.html` に対応します。

## 相対パス

- **リンク**：VitePress は Markdown のリンクを書かれたとおりに出力し、ブラウザーがページのパスを基準に解決します。記事のパスは `/theme/layout/` ではなく `/theme/layout` なので、その中の `./sidebar` は記事フォルダー内のファイルではなく `/theme/sidebar` を指します。そのため、内部リンクは完全なパスで書いてください。
- **画像とアセット**：Vite は画像をモジュールとしてインポートし、ソースファイルの場所から解決します。そのため、`./image.png` は記事フォルダー内のファイルを指します。小さな画像はデータ URL としてインライン化され、それ以外はビルド時にハッシュ付きで出力にコピーされます。

## ナビゲーションの生成方法

各言語のナビゲーションは、その言語フォルダーから次のルールで生成されます。

- **カテゴリ**：言語フォルダー内の各フォルダーがカテゴリです。順序は、共通設定の `sidebar.categories` のキーの順、次に言語設定にだけあるキー、最後に `categories` にないフォルダーを名前順に並べます。記事のないカテゴリは表示されません。カテゴリの名前は `text` で、ない場合はフォルダー名です。
- **記事**：カテゴリフォルダー内の、`index.md` を持つ各フォルダーです。名前はフロントマターの `title`、次に最初の h1 見出し、次にフォルダー名の順で決まります。並べ替えではまず `order` を比較します。`order` のない記事は最後になり、同順の場合はフォルダー名で並べます。
- **ホームページ**：言語フォルダーの `index.md` は、デフォルトではナビゲーションに含まれません。`category` を指定するとそのカテゴリに加わり、`order` がなければカテゴリの先頭になります。
- **並列ページ**：`parallel` の各エントリーが順番に 1 つのタブになり、記事自身が最初のタブです。ナビゲーションの項目自体にはリンクがなく、最初のタブがその代わりになります。並列ページが単独でナビゲーションに表示されることはありません。
- **h1 見出しの検出**：フェンスで囲まれたコードブロックはスキップし、`# ` で始まる最初の行を取り、その Markdown 記法を取り除きます。

生成されたナビゲーションは、手書きの `sidebar.items`（`AkariSidebarItem`）と同じ構造です。そのため、展開、ハイライト、ページ送り、フッターのリンク列もまったく同じように動作します。

## 通知

ナビゲーションの生成中、次の場合にターミナルに通知が表示されます。各通知は 1 回だけ表示されます。

- `parallel` に挙げたファイルが存在しない、または記事フォルダー内のファイル名ではない（たとえばパスを書いた）。そのエントリーはスキップされます。
- ページがナビゲーションの構造に含まれない：カテゴリフォルダーに直接置いた `.md`、さらに深い階層のファイル、どの記事も並列ページとして挙げていないファイル。これらもページにはなりますが、ナビゲーションには表示されません。
- `rootLanguage` で指定したフォルダーが言語フォルダーではない。

## 対応するページ

言語を切り替えると、テーマは現在のパスを切り替え先の言語に移します（`/theme/i18n.html` ↔ `/zh-CN/theme/i18n.html`）。切り替え先の言語のナビゲーションにそのパスがあればそれを開き、なければその言語のホームページを開きます。つまり、2 つのページがそれぞれの言語フォルダーで同じパスにあり、切り替え先のページがその言語のナビゲーションに含まれていれば、言語を切り替えても同じページにとどまります。

## 検索インデックス

ローカル検索インデックスは VitePress が作るので、そのリンクは（上の書き換えの後の）ページの実際のパスになります。インデックスは言語ごとに 1 つです。各ページは見出しでセクションに分割されます。レベル 1 の見出しの下の部分がページ自体を表し、並列ページは独自のページとして扱われます。
