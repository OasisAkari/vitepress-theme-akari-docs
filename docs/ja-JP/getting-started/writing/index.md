# ページの作成

ページは、言語フォルダー内の Markdown ファイルです。置く場所によって、そのパスとナビゲーション内の位置が決まります。

## 記事を作成する

1. カテゴリフォルダーの中にフォルダーを作成します。フォルダー名が記事のパスになります。小文字の英字、数字、ハイフンだけを使ってください。
2. その中に、h1 見出しで始まる `index.md` を書きます。
3. フロントマターでアイコンと順序を指定します。

```text
docs/ja-JP/components/
└─ chip/
   └─ index.md          /ja-JP/components/chip
```

```md
---
icon: label
order: 4
---

# チップ

本文…
```

保存すると、開発サーバーを再起動しなくても、記事はすぐに「コンポーネント」カテゴリに表示されます。ナビゲーションでの名前はページのタイトルで、ここでは「チップ」です。

カテゴリを追加するには、カテゴリフォルダーを作成し、共通設定の `sidebar.categories` でアイコンを、言語設定で名前を指定します。[構成](/ja-JP/getting-started/configuration) を参照してください。

## 並列ページ {#parallel-pages}

長い記事は複数のページに分け、ページ上部のタブバーで切り替えられます。サイドバーには 1 つの項目だけが表示されたままです。記事フォルダーに `.md` ファイルを追加し、`index.md` のフロントマターに順番に並べます。

```text
docs/ja-JP/styles/icons/
├─ index.md           /ja-JP/styles/icons
├─ choosing.md        /ja-JP/styles/icons/choosing
└─ using.md           /ja-JP/styles/icons/using
```

```md
---
title: アイコン
tab: 概要
parallel:
  - choosing
  - using
---
```

各ページは、自身の `tab` でタブバーでのタイトルを設定します。指定しない場合はページのタイトルが使われます。このサイトのテーマのページは、すべて「概要」「API」「詳細」の 3 ページに分かれています。

## ヒーロー

フロントマターに `hero` を書くと、ページ上部にタイトルカードと画像が並んで表示されます。[ヒーロー](/ja-JP/theme/hero) を参照してください。

## 画像とリンク

- 1 つのページでしか使わない画像は記事フォルダーに置き、`![説明](./image.png)` のように参照します。複数のページで共有する画像は `docs/public` に置き、`/hero/image.svg` のような絶対パスで参照します。
- 画像の幅と高さはレンダリング時に自動で書き込まれます。リモート画像も同様です。そのため、画像の読み込み中にページがずれません。[API](/ja-JP/getting-started/writing/api#images) を参照してください。
- 内部リンクにはページのパスを使い、`/` で始めます：`[サイドナビゲーション](/theme/sidebar)`。ファイルパス（`/zh-CN/theme/sidebar/index.md`）や相対パスは書かないでください。
- 日本語のページ間のリンクには `/ja-JP/` の接頭辞を付けます。

## Markdown

VitePress の Markdown 拡張はすべて使えます。たとえばコードグループ、カスタムコンテナ、コードブロックの行のハイライト、脚注などです。テーマはさらにいくつかの機能を加えています。

- テーブルには M3 のアウトラインの枠線が付き、本文のリンクの前にはアイコンが付きます。コードブロックやテーブルなど背景のある要素には、薄いパターンが入ります。
- `<m3e-button>` や `<m3e-card>` などの m3e コンポーネントを Markdown に直接書けます。このサイトのコンポーネントのデモはこの方法で書いています。
- デモの内容をレイアウトするためのヘルパークラスがいくつかあります：`demo-surface`、`demo-row`、`demo-grid`、`demo-stack`。

フロントマターの全フィールド、使えるコンポーネント、ヘルパークラスは [API](/ja-JP/getting-started/writing/api) を参照してください。

## ほかの言語の版

別の言語フォルダーの同じ場所に同じ名前のフォルダーを置きます。たとえば `docs/zh-CN/components/chip/index.md` です。すると 2 つのページは互いに対応するページとなり、言語を切り替えてもこのページにとどまります。対応するページがない場合、言語を切り替えるとその言語のホームページに移動します。
