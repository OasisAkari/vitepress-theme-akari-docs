# 画像プレビュー

`AkariImagePreview` は画像を押し開けるサムネイルに包みます。開くと本文領域いっぱいに広がり、拡大・回転・移動ができ、キーボードでも同じ操作ができます。

## 使い方

<AkariImagePreview src="/hero/theme-hero.svg" alt="テーマの外観" label="テーマの外観を見る">
  <img src="/hero/theme-hero.svg" alt="テーマの外観" width="360" />
</AkariImagePreview>

```html
<AkariImagePreview src="/hero/theme-hero.svg" alt="テーマの外観">
  <img src="/hero/theme-hero.svg" alt="テーマの外観" width="360" />
</AkariImagePreview>
```

既定のスロットはサムネイルそのものです。省略するとコンポーネントが `<img>` を自分で描画し、渡すとその組版をそのまま使って、外側をボタンで包むだけになります。

プロパティ、スロット、CSS クラス、エクスポートされる幾何関数は「API」にあります。

## キーボード

| キー | 動作 |
| --- | --- |
| `Esc` | プレビューを閉じる |
| `+`、`=` | 一段階拡大 |
| `-`、`_` | 一段階縮小 |
| `0` | 表示を初期化 |
| `r` | 時計回りに 90° 回転 |
| `Shift` + `r` | 反時計回りに 90° 回転 |

拡大率は 50%〜400% で、ホイール、ダブルクリック、ツールバーのボタンから操作できます。押したままドラッグすると移動でき、画像のダブルクリックかツールバーの初期化ボタンで最初の表示に戻ります。

## モーションとフォールバック

開くときはサムネイルの位置から画像が広がり、閉じるときは元へ縮みます。表示を拡大・回転・移動したあとは、戻る先の一つの箱がなくなるため、このアニメーションは飛ばしてフェードだけにします。「視差効果を減らす」が有効なときは最初からフェードのみです。

プレビュー層は `.akari-frame` にテレポートするため、本文の組版や `overflow` に切り取られません。開いている間はページのスクロールを止め、閉じたあとはフォーカスをトリガーのボタンに戻します。
