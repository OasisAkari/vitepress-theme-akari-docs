# 検索

検索はアプリバーの右側にあります。広い画面ではプレースホルダーテキストとショートカットのヒントのある検索ボックスで、狭い画面では丸いボタンに縮みます。クリックするか `⌘K`（Windows と Linux では `Ctrl K`）を押すと、検索ボックスが検索パネルに展開します。

## 使い方

| キー | 操作 |
| --- | --- |
| `⌘K` / `Ctrl K` | どのページからでも検索を開く |
| `↑` / `↓` | 結果の間を移動する |
| `Enter` | 現在の結果を開く |
| `Esc` | 検索を閉じる |

結果はページとセクションごとに並び、それぞれに一致した部分の抜粋が付きます。セクションの結果を開くと、その見出しまでスクロールします。多言語のサイトでは、現在の言語のページだけが返されます。

## ローカルインデックス

デフォルトではバックエンドは不要です。開発時とビルド時に、テーマがすべての Markdown ページを走査して `docs/public/search-index.json` を書き出します。ページごとに 1 項目、さらにレベル 2 とレベル 3 の見出しごとに 1 項目です。インデックスはリポジトリにコミットしません。`npm run dev` と `npm run build` が自動で更新します。

## 別の検索を使う

スペルの訂正、セマンティック検索、サイト外のコンテンツが必要なときは、HTTP エンドポイントや独自の JS 関数に切り替えます。

```ts
// docs/config.ts
search: {
  backend: { type: "http", endpoint: "/api/docs/search" },
},
```

バックエンドの書き方と結果の形式は [API](/ja-JP/theme/search/api) を、パネルのモーションとインデックスの構築・順位付けの仕組みは[詳細](/ja-JP/theme/search/details)を参照してください。
