# ヒーロー：詳細

## 色の抽出

ヒーローのあるページは、画像から色を取り出してテーマのシードカラーにします。

- Material 公式の [material-color-utilities](https://github.com/material-foundation/material-color-utilities) を使います。画像を 128px 以下に縮小し、主要な色に量子化してから、インターフェースのテーマにどれだけ合うかで各色を採点します。これは Android が壁紙から色を取り出すのと同じアルゴリズムです。透明なピクセルと、くすみすぎた色は除外されます。
- 抽出はブラウザーで行われ、結果は画像の URL ごとに `localStorage` にキャッシュされるため、次回以降の訪問ではすぐに反映されます。初回の訪問では、画像の読み込み後にページの色が一度変わります。色のライブラリはヒーローのあるページでのみオンデマンドで読み込まれ、ほかのページやサーバーサイドレンダリングには含まれません。
- ダークモードで `dark` の画像が表示されているときは、その画像から色を取り出します。
- 別ドメインの画像は、サーバーが CORS ヘッダーを送らないとピクセルを読み取れません。その場合は読者の色のままになります。`color` で色を直接指定することもできます。
- 画像に十分鮮やかな色がない場合も、読者の色のままになります。

## タイトル

ヒーローを設定すると、ページのタイトルはヒーローのカードに表示され、Markdown の最初の `# Title` は非表示になります。そのため、ページに表示される `h1` は 1 つだけのままです。タイトルのテキストはフロントマターの `title` から取得し、ない場合は最初の `#` 見出しから取得します。これは VitePress のページタイトルの規則と同じです。ヒーロー内のタイトルには `data-akari-page-title` が付いており、アプリバーの下にスクロールすると、アプリバーにページのタイトルが表示されます。

日付はページの言語に合わせて書式化されます。`2026-05-19` は、中国語のページでは「2026年5月19日」、日本語のページでも「2026年5月19日」と表示されます。

## レイアウト

- 2 枚のカードはドキュメントサーフェスの上部を埋め、コンテンツの `--akari-doc-max-width` には制限されません。カードとサーフェスの上端・左端・右端との距離、および 2 枚のカードの間隔は、すべて `--akari-doc-hero-inset` です。カードの角はサーフェスの角と同心円になります。
- タイトルのサイズとカードのパディングは、ウィンドウの幅ではなくヒーロー自体の幅に応じて変わります（コンテナクエリ）。ナビゲーションドロワーが開いて使える幅が狭くなると、タイトルもそれに合わせて小さくなります。
- ウィンドウの幅が 840px より狭いときは 2 枚のカードが縦に並び、テキストが上、画像が 16:10 で表示されます。
- ページが並列ページのグループに属している場合、タブバーはヒーローの上にあり、ヒーローはタブバーから同じ距離だけ下に置かれます。これにより、グループのどのページでもタブバーが同じ位置に保たれ、ヒーローのあるページとないページを切り替えてもタブバーがずれません。
- 画像には `fetchpriority="high"` が付いているため、最初の画面で最も大きい要素として最優先で読み込まれます。ヒーローはドキュメントサーフェスの中にあるので、ページが変わるときはサーフェスと一緒にフェードアウト・フェードインします。

## パターンと光

- 2 枚のカードは同じパターンを使います。パターンはテキストカードの上部の末尾側の角と、画像カードの下部の先頭側の角で最もはっきりしており、そこから薄れていくので、2 枚を合わせると対角線を描きます。
- 画像カードのパターンは画像の下にあり、画像が透明な部分にだけ見えます。カードを埋める写真ではパターンは完全に隠れます。
- ポインターをカードに置くと、その周囲がテーマカラーでごくかすかに光ります。光の内側ではパターンが少しはっきり見え、光の縁は段階的に薄れ、ポインターが離れると光は消えていきます。ドキュメントサーフェスの `pointermove` ハンドラーが毎フレーム光の位置（`--_x`、`--_y`）を書き込み、マウスとペンにのみ反応します。
- パターンはブラウザーで選ばれます。サーバーサイドレンダリングにはパターンがなく、マウント後にフェードインするため、サーバーとブラウザーのページが一致し、ハイドレーションの不一致は起きません。
- タッチデバイスでは静的なパターンだけが表示され、強制カラーモードでは装飾は表示されません。装飾はテキストと画像の下にあるため、選択やクリックの妨げになりません。

コンテンツ内の背景を持つ要素も同じパターンのセットを使います。[タイポグラフィ](/ja-JP/styles/typography/api#patterns)を参照してください。
