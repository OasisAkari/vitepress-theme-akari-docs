# ヒーロー

[Material Design ブログ](https://m3.material.io/blog)のように、ページにヒーロー画像を付けられます。ドキュメントサーフェスの上部に 2 枚のカードが並び、左に日付、タイトル、概要、右に画像が表示されます。このページの上部がその例です。

## ヒーローを追加する

ページのフロントマターに `hero` を書きます。

```yaml
---
title: Google I/O 2026 の新機能
hero:
  image: /hero/io-2026.png
  alt: スマートフォンとタブレットに表示した新しいコンポーネント
  date: 2026-05-19
  tagline: Material の最新アップデートで、表現力豊かでアダプティブなプロダクトをより簡単に作れます
---
```

画像だけが必要なら、短い書き方を使えます。

```yaml
hero: /hero/io-2026.png
```

ページのタイトルはヒーローのカードに表示され、コンテンツの先頭にあるレベル 1 の見出しは非表示になります。

## ダークモード用の画像

ダークモード用に別の画像を用意するには、`light` と `dark` を書きます。

```yaml
hero:
  image:
    light: /hero/io-2026.png
    dark: /hero/io-2026-dark.png
    alt: スマートフォンとタブレットに表示した新しいコンポーネント
```

ライトモードとダークモードを切り替えると画像もすぐに切り替わり、画面に表示されていない方の画像はダウンロードされません。

## カラー

ヒーローのあるページは画像から色を取り出してテーマカラーにし、アプリバー、ナビゲーション、ボタン、リンクが画像に合うパレットに切り替わります。ページを離れると、読者自身の色に戻ります。`color: "#3367d6"` と書くと色を固定し、`color: false` と書くと読者の色を維持します。

## 透過画像とパターン

背景が透明なイラストには `fit: contain` が合います。画像全体が表示され、カードの内側に余白が付きます。2 枚のカードにはごく薄いパターンがあり、ポインターをカードに置くと、その周囲が柔らかく光ります。パターンは透過画像の背後にも表示されます。パターンは `pattern` で選び、`none` と書くとオフになります。

すべてのフィールドは [API](/ja-JP/theme/hero/api) を参照してください。色の抽出、レイアウト、パターンの仕組みは[詳細](/ja-JP/theme/hero/details)を参照してください。
