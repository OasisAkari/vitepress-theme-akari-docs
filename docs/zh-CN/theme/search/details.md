# 搜索：技术细节

## 容器变换

搜索面板是原生的模态 `<dialog>`，用 Web Animations API 以 M3 容器变换展开。语言选择与设置模态框使用同一套实现（`useContainerTransform`）。

- 动画的对象始终是真实的面板，它从第一帧起就按最终尺寸排版。开始时只通过一个与按钮同形的窗口（`clip-path` 胶囊）露出面板自己搜索栏的起始端，并用位移把这个窗口放到按钮上，所以第一帧看到的仍是「图标 + 占位文字」的搜索框。
- 展开时位移归零，窗口扩大到整个面板（包括阴影），内容随之逐步显露，结果区与关闭按钮同时淡入，中途不会出现空白的表面。动画结束时的状态就是面板的静止样式，移除动画不会跳变。
- 按钮的一份像素副本叠在窗口上随之移动。按钮与面板的内容不交叉叠化，而是先后淡出淡入（M3 的 fade through）：打开时面板表面先在副本下方淡入，副本随后淡出，面板自己的搜索栏再淡入，两种大小不同的文字不会同时出现。
- 关闭时原路收回：结果区与搜索栏先淡出，按钮副本在途中淡入接替，面板表面随后在它下方淡出。落回按钮的最后一段，包括表现力动效的回弹，看到的都是按钮本身，结束时与真实按钮完全一致；没有底色的按钮（例如齿轮按钮）因此也不会在结束时闪出一块底色。打开或关闭途中被打断时，从当前帧继续反向运动。
- 窗口的尺寸与圆角取自按钮当前的位置与大小，面板位置在动画开始时重新测量，不依赖固定坐标。

| 动效 | 展开 | 收回 |
| --- | --- | --- |
| 标准 | 约 300ms，`cubic-bezier(0.2, 0, 0, 1)` | 约 250ms，不回弹 |
| 表现力 | 约 500ms，`cubic-bezier(0.38, 1.21, 0.22, 1)`，略微越过后回稳 | 约 400ms，同样的曲线，收回时带一点回弹 |

系统开启「减少动态效果」时直接显示与关闭。原生 dialog 提供顶层显示、背景 inert 与 `Esc` 关闭；打开时焦点进入输入框，关闭后回到打开前的焦点，没有可用焦点时回到搜索按钮。

## 索引的生成

- Vite 插件在开发服务器启动与构建开始时扫描 `docs` 中所有的 `.md`（`.vitepress`、`public` 与以 `.` 开头的目录除外），写出 `docs/public/search-index.json`；开发时 Markdown 增删改后约 150ms 重新生成。构建结束时把它复制到产物根目录。
- 页面地址由 `content.route` 计算，与页面实际的地址一致。
- 页面标题取头部信息的 `title`，其次是第一个一级标题，再次是文件名。
- 每个二级、三级标题生成一个章节条目，锚点与 VitePress 生成的标题 id 一致。
- 围栏代码块不进入索引；HTML 标签、链接地址与 Markdown 标记会被去掉，只保留文字。每个条目的正文最多 4000 字。

## 匹配与排序

查询先归一化（统一大小写与全半角等）并按空白切分为词，每个词都要出现在条目的标题、页面标题或正文中，条目才算命中。得分按以下规则累加，表中的「标题」是条目自己的标题：页面条目为页面标题，章节条目为章节标题：

| 条件 | 分数 |
| --- | --- |
| 标题与整个查询完全相同 | +100 |
| 标题以整个查询开头 | +60 |
| 标题包含整个查询 | +40 |
| 页面标题包含整个查询 | +20 |
| 正文包含整个查询 | +10 |
| 每个词：出现在标题 / 页面标题 / 正文中 | +24 / +10 / +6 |
| 条目层级：页面 / 二级标题 / 三级标题 | +3 / +2 / +1 |

结果按得分从高到低排列，同分时按标题排序，同一地址只保留一条，最多返回 `maxResults` 条。多语言站点中，本地索引包含所有语言的页面，结果只保留当前语言路径下的条目（根语言不包含 `/<语言文件夹>/` 下的页面）。

## 加载与缓存

- 本地索引在第一次搜索时加载，之后在页面中缓存；开发模式下不使用浏览器缓存，修改后的内容可以立即搜到。
- 输入有 `debounce` 的防抖；输入新查询或关闭面板时，进行中的请求通过 `AbortSignal` 中止。
- 索引文件缺失或格式错误时，面板显示错误与重试按钮。

## 面板的状态

| 状态 | 显示 |
| --- | --- |
| 空输入 | 搜索提示与快捷键说明 |
| 加载中 | M3 加载指示器 |
| 有结果 | 页面标题、章节标题、摘要与命中高亮；当前项使用 `secondary-container` 底色 |
| 无结果 | 提示换一个关键词 |
| 失败 | 错误原因与重试按钮 |

结果跳转使用 VitePress 的路由，保持 SPA 导航。输入框、结果列表与错误提示都有对应的 ARIA 名称。顶栏的快捷键提示使用 `label-small` 字体与全圆角的键帽；面板中的方向键、`Enter` 与 `Esc` 提示使用 `shape-extra-small` 圆角。

## 已知限制

- 本地索引是简单的子串匹配，没有拼写纠错与语义搜索；需要时接入 HTTP 或注册的后端。
- 本地索引只在开发服务器运行或构建时刷新；开发服务器没有运行时直接修改的 Markdown，要等下一次 `npm run dev` 或 `npm run build` 才能搜到。
