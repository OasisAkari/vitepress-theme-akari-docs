# 头图：技术细节

## 取色

带头图的页面从图片中取一个颜色作为主题的种子色。

- 使用 Material 官方的 [material-color-utilities](https://github.com/material-foundation/material-color-utilities)：把图片缩到 128px 以内，量化出主要颜色，再按是否适合作为界面主题打分，与 Android 从壁纸取色的算法相同。透明像素与过于灰暗的颜色不参与。
- 取色在浏览器中进行，结果按图片地址缓存在 `localStorage`，再次访问时立即生效；首次访问时，页面在图片加载完成后换一次色。取色库只在头图页面按需加载，不进入其他页面与服务端渲染。
- 夜间显示 `dark` 图片时，从它取色。
- 其他域名的图片需要服务端返回 CORS 头才能读取像素，否则保持读者的颜色；也可以用 `color` 直接指定。
- 图片中找不到足够鲜明的颜色时，同样保持读者的颜色。

## 标题

配置头图后，页面标题显示在头图卡片中，Markdown 中的第一个 `# 标题` 被隐藏，页面仍然只有一个可见的 `h1`。标题文字取头部信息的 `title`，没有时取第一个 `#` 标题，与 VitePress 的页面标题规则一致。头图中的标题带 `data-akari-page-title`，它滚到顶栏下方后，顶栏显示页面标题。

日期按页面语言格式化：`2026-05-19` 在中文页面显示为「2026年5月19日」，在英文页面显示为「May 19, 2026」。

## 排版

- 两张卡片占满文档表面的顶部，不受正文的 `--akari-doc-max-width` 限制。卡片与表面上、左、右边缘的距离，以及两张卡片之间的距离，都是 `--akari-doc-hero-inset`；卡片圆角与表面圆角同心。
- 标题字号与卡片内边距按头图自身的宽度缩放（容器查询），而不是按窗口宽度：导航抽屉展开、可用空间变窄时，标题随之缩小。
- 窗口窄于 840px 时两张卡片上下堆叠，文字在上，图片按 16:10 显示。
- 页面属于一组平行页面时，标签栏排在头图上方，头图在标签栏下方隔开同样的距离。这样组内各页的标签栏位置一致，在有头图与没有头图的页面之间切换时不会跳动。
- 图片带 `fetchpriority="high"`，作为首屏最大的元素优先加载。头图在文档表面中，切换页面时随表面一起淡出淡入。

## 图案与柔光

- 两张卡片用同一种图案：文字卡片在末端上角最清楚，图片卡片在起始下角最清楚，各自渐隐，合起来是一条对角线。
- 图片卡片的图案在图片之下，只在图片透明的地方露出；铺满的照片会把它完全盖住。
- 指针停在卡片上时，周围亮起一圈很淡的主题色柔光，柔光中的图案清楚一些，边缘逐级淡出，移开时淡出。柔光的位置由文档表面上的一个 `pointermove` 处理函数每帧写入（`--_x`、`--_y`），只响应鼠标与触控笔。
- 图案在浏览器中挑选，服务端渲染不带图案，挂载后淡入，因此服务端与浏览器的页面一致，不会出现水合差异。
- 触屏设备只显示静态图案，强制颜色模式下不显示装饰；装饰在文字与图片之下，不影响选择与点击。

正文中带背景的元素使用同一套图案，见[排版](/styles/typography/api#图案)。
