# 国际化：技术细节

## 页面属于哪种语言

语言由地址决定：地址以 `/<语言文件夹>/` 开头的页面属于那种语言，其余都属于根语言。根语言的页面在源码中位于它自己的文件夹（`docs/zh-CN/`），提供时去掉了文件夹名，见[撰写页面 · 技术细节](/getting-started/writing/details#地址规则)。

一个页面最终使用的配置，是它所在语言文件夹的 `config.ts` 叠在共用配置与 VitePress 的 locale 配置之上的结果，见[配置 · 技术细节](/getting-started/configuration/details#两层配置怎样叠加)。

## 界面文字的选择

1. 取当前语言的 `lang`，转为小写后与内置的语言（`zh`、`en`、`ja`、`ko`、`fr`、`ar`）比较完整代码。
2. 不匹配时比较主语言：`zh-CN`、`zh-TW` 都使用中文，`en-GB` 使用英文，`fr-CA` 使用法文。
3. 仍不匹配时使用英文。
4. 语言配置的 `messages` 中写出的条目替换内置文字。

`settings.title`、`settings.labels`、`toc.overline`、`footer.message` 与 `search.placeholder` 没有写时，也取自这张表，所以同一份共用配置在每种语言下都有合适的默认值。写在共用配置中的文字会被所有语言继承，需要按语言区分的文字要写在语言配置里。

## 切换语言的目标

1. 把当前地址换到目标语言下：`/getting-started/installation` → `/en-US/getting-started/installation`，反向时去掉前缀。
2. 目标语言的导航中有这个地址时打开它；导航包括平行页面组中的每一页。
3. 否则打开目标语言的首页：根语言为 `/`，其他语言为 `/<语言文件夹>/`。

判断只看目标语言的导航，所以没有进导航的页面（例如结构之外的页面）不会成为切换的目标。

## 语言对话框

- 语言按钮是一个圆形描边图标按钮（`m3e-icon-button variant="outlined"`），只有一种语言时不渲染。
- 对话框与搜索面板使用同一种容器变换：按钮展开为居中的面板，面板标题前的图标就是按钮本身，关闭时原路收回。
- 列表中每种语言占两行：上一行是它的 `label`，下一行是它在当前界面语言中的名称，由 `Intl.DisplayNames` 生成（中文界面中 `en-US` 显示为「英语（美国）」）。当前语言高亮，带勾选图标。
- 点击切换语言并关闭对话框，走 SPA 导航；按住 `⌘`、`Ctrl` 等修饰键点击时在新标签页打开。
- 打开时焦点落在当前语言上，`Tab` 在语言之间移动；`Esc`、点击遮罩或关闭按钮收起对话框，焦点回到语言按钮。
- 窄屏时按钮在导航抽屉底部，对话框覆盖在抽屉之上。

## 搜索范围

本地索引只有一份，包含所有语言的页面。搜索时，结果只保留与当前页面属于同一种语言的条目：根语言的结果不包括 `/<语言文件夹>/` 下的页面。搜索面板的文字与错误提示随语言切换。
