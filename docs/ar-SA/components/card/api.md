# البطاقات: API

المحتوى أدناه مأخوذ من البيانات الوصفية لمكونات `@m3e/web` 2.10.2.

## m3e-card

| الخاصية | القيم | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `variant` | `elevated`، `filled`، `outlined` | `filled` | المظهر |
| `orientation` | `vertical`، `horizontal` | `vertical` | اتجاه ترتيب المحتوى |
| `inline` | منطقية | `false` | يرتّب البطاقة عنصرًا ضمن السطر |
| `actionable` | منطقية | `false` | يجعل البطاقة كلها منطقة تفاعل واحدة |
| `href`، `target`، `rel`، `download` | كما في الزر | كما في الزر | يجعل البطاقة رابطًا عند ضبط `actionable` |
| `disabled`، `disabled-interactive` | منطقية | `false` | يعطّل البطاقة عند ضبط `actionable` |
| `type`، `name`، `value` | كما في الزر | `button` | السلوك داخل نموذج عند ضبط `actionable` |

| المنفذ | المحتوى |
| --- | --- |
| (الافتراضي) | دون حشوة؛ يناسب الصور الممتدة حتى الحواف أو التخطيطات المخصصة |
| `header` | عنوان أو أيقونة أو وسائط، دون حشوة إضافية |
| `content` | المتن، مع حشوة |
| `actions` | أزرار الإجراءات، محاذاة إلى حافة البداية افتراضيًا؛ أضف الخاصية `end` إلى العنصر لمحاذاتها إلى حافة النهاية |
| `footer` | البيانات الوصفية أو حقوق النشر أو الملاحظات الثانوية |

| الحدث | متى |
| --- | --- |
| `click` | عند النقر على بطاقة `actionable` |

## m3e-dialog

| الخاصية | القيم | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `open` | منطقية | `false` | هل مربع الحوار مفتوح |
| `dismissible` | منطقية | `false` | يُظهر زر إغلاق |
| `disable-close` | منطقية | `false` | يمنع الإغلاق بالنقر على طبقة التعتيم أو بالضغط على `Esc` |
| `alert` | منطقية | `false` | يعمل مربعَ حوار تنبيه |
| `close-label` | نص | `"Close"` | اسم زر الإغلاق لدى التقنيات المساعدة |
| `no-focus-trap` | منطقية | `false` | لا يُبقي تركيز `Tab` داخل مربع الحوار |

| المنفذ | المحتوى |
| --- | --- |
| (الافتراضي) | المتن |
| `header` | العنوان |
| `actions` | أزرار الإجراءات |
| `close-icon` | أيقونة زر الإغلاق |

| الحدث | متى |
| --- | --- |
| `opening`، `opened` | بدء الفتح، انتهاء الفتح |
| `closing`، `closed` | بدء الإغلاق، انتهاء الإغلاق |
| `cancel` | الإلغاء عبر طبقة التعتيم أو `Esc` |

يوضع `m3e-dialog-trigger` (الخاصية `for`: معرّف مربع الحوار) داخل زر ويفتح مربع الحوار عند النقر على الزر. ويوضع `m3e-dialog-action` (الخاصية `return-value`) داخل زر في مربع الحوار؛ والنقر عليه يغلق مربع الحوار ويعيد تلك القيمة.

## تخصيص المظهر

تتحكم متغيرات `--m3e-card-*` في نصف قطر زوايا البطاقة ولونها وحشوتها. مثلًا، `--m3e-card-shape` هو نصف قطر الزوايا:

```html
<m3e-card variant="outlined" style="--m3e-card-shape: 28px;">…</m3e-card>
```

يسجّل الملف `m3e.ts` في السمة هذه المكونات (`@m3e/web/card`، `@m3e/web/dialog`).
