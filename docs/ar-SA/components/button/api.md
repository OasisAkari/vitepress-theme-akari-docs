# الأزرار: API

المحتوى أدناه مأخوذ من البيانات الوصفية لمكونات `@m3e/web` 2.10.2.

## m3e-button

| الخاصية | القيم | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `variant` | `elevated`، `filled`، `tonal`، `outlined`، `text` | `text` | المظهر |
| `size` | `extra-small`، `small`، `medium`، `large`، `extra-large` | `small` | الحجم |
| `shape` | `rounded`، `square` | `rounded` | الشكل |
| `disabled` | منطقية | `false` | معطّل وغير قابل للتركيز |
| `disabled-interactive` | منطقية | `false` | معطّل لكنه يظل قابلًا للتركيز، ليتمكن القراء من اكتشاف الإجراء |
| `toggle` | منطقية | `false` | يعمل مفتاحَ تبديل بحالتين |
| `selected` | منطقية | `false` | حالة التحديد لمفتاح التبديل |
| `href` | نص | `""` | يجعل الزر رابطًا عند ضبطه |
| `target` | `_self`، `_blank`، `_parent`، `_top` أو اسم نافذة | `""` | مكان فتح الرابط |
| `rel` | نص | `""` | العلاقة بين الرابط والصفحة الحالية |
| `download` | نص | لا يوجد | يجعله رابط تنزيل؛ والقيمة هي اسم الملف |
| `type` | `button`، `submit`، `reset` | `button` | السلوك داخل نموذج |
| `name`، `value` | نص | لا يوجد | الاسم والقيمة المرسَلان عند إرسال النموذج |

| المنفذ | المحتوى |
| --- | --- |
| (الافتراضي) | نص الزر |
| `icon` | أيقونة قبل النص |
| `trailing-icon` | أيقونة بعد النص |
| `selected` | النص عند التحديد |
| `selected-icon` | الأيقونة عند التحديد |

| الحدث | متى |
| --- | --- |
| `click` | عند النقر |
| `beforeinput` | مفتاح التبديل على وشك التبديل؛ ويمكن إلغاؤه |
| `input`، `change` | تبدّل مفتاح التبديل |

## m3e-icon-button

الخصائص نفسها التي في `m3e-button`، بالإضافة إلى:

| الخاصية | القيم | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `variant` | `standard`، `filled`، `tonal`، `outlined`، `elevated` | `standard` | المظهر |
| `width` | `default`، `narrow`، `wide` | `default` | العرض |

| المنفذ | المحتوى |
| --- | --- |
| (الافتراضي) | الأيقونة |
| `selected` | الأيقونة عند التحديد |

الأحداث هي نفسها التي في `m3e-button`.

## m3e-tooltip

| الخاصية | القيم | القيمة الافتراضية | الوصف |
| --- | --- | --- | --- |
| `for` | معرّف عنصر | لا يوجد | عنصر التحكم الذي ينتمي إليه التلميح |
| `position` | `above`، `below`، `before`، `after` | `below` | الموضع بالنسبة إلى عنصر التحكم |
| `show-delay` | بالمللي ثانية | `0` | التأخير قبل الإظهار |
| `hide-delay` | بالمللي ثانية | `200` | التأخير قبل الإخفاء |
| `touch-gestures` | `auto`، `on`، `off` | `auto` | طريقة التعامل مع إيماءات اللمس |
| `disabled` | منطقية | `false` | يعطّل التلميح |

## استخدام الأزرار في التوثيق

- يقع عنصر الرابط في الزر داخل Shadow DOM الخاص به، حيث لا تستطيع معالجة VitePress للروابط الداخلية رؤيته، لذا يحمّل `m3e-button` الداخلي الذي له `href` الصفحة كاملة. عندما تحتاج إلى تنقل SPA، استخدم عنصر `<a>` عاديًا، أو استدعِ `useRouter().go()` عند النقر. راجع [التنقل](/ar-SA/components/navigation#spa-navigation).
- مهما كان حجمه المرئي، يحتفظ الزر بمنطقة لمس لا تقل عن 48×48dp.
- يسجّل الملف `m3e.ts` في السمة هذه المكونات (`@m3e/web/button`، `@m3e/web/icon-button`، `@m3e/web/tooltip`).
