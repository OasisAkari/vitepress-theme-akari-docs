# التدويل

كل لغة هي مجلد داخل `docs` يحمل اسم رمز اللغة، مثل `zh-CN` أو `en-US`. تُقدَّم اللغة الجذرية في جذر الموقع؛ أما مسارات اللغات الأخرى فتبدأ باسم مجلدها. تحدّد لغة الصفحة الحالية نصوص الواجهة والتنقل والتذييل ونطاق البحث.

ما يخص اللغة نفسها (نصوص واجهتها وخطوطها واتجاه نصها ونصوصها في Markdown) لا يُكتب في تهيئة الموقع، بل يوجد في [حزمة اللغة](#language-packs) التي تُختار برمز اللغة. لذا لا تحتاج إضافة لغة إلا إلى ما يخص هذا الموقع.

## إضافة لغة

1. أنشئ مجلدًا داخل `docs` يحمل اسم رمز اللغة، واكتب فيه ملف `config.ts`:

   ```ts
   // docs/ar-SA/config.ts
   import { defineAkariConfig } from "../.vitepress/theme/define.ts";

   export default defineAkariConfig({
     title: "Vitepress Theme Akari Docs",
     appBar: { title: "Vitepress Theme Akari Docs" },
     sidebar: {
       categories: {
         "getting-started": { text: "البدء" },
         theme: { text: "السمة" },
       },
     },
     footer: { message: "صُنع باستخدام VitePress و M3E Web Components" },
   });
   ```

2. أضف الصفحات بالبنية نفسها التي تتبعها اللغة الجذرية: `docs/ar-SA/index.md` هي الصفحة الرئيسية لهذه اللغة، و`docs/ar-SA/getting-started/installation/index.md` تقابل الصفحة الصينية `/getting-started/installation`.
3. عند الحاجة، اضبط `rootLanguage` في التهيئة المشتركة لاختيار اللغة التي تُقدَّم في الجذر.

تُطبَّق تهيئة اللغة فوق التهيئة المشتركة، لذا لا تحتاج إلا إلى عناوين اللغة وأسماء الفئات. أما رقم الإصدار والروابط الاجتماعية وأيقونات الفئات وما شابهها فتأتي من التهيئة المشتركة. الاسم في قائمة اللغات هو افتراضيًا اسم اللغة بلغتها نفسها (English، 日本語)، أما اتجاه النص ونصوص الواجهة وزر النسخ في كتل الشيفرة وعناوين الحاويات فتأتي من حزمة اللغة. ويمكن لتهيئة اللغة أن تستبدل أيًّا منها.

## تبديل اللغة

عندما يحتوي الموقع على لغتين أو أكثر، يظهر زر اللغة أسفل شريط التنقل (rail) (وأسفل درج التنقل على الشاشات الضيقة). يفتح النقر عليه مربع الحوار «اختر لغة».

- إذا كانت في اللغة المستهدفة صفحة مقابلة، تبقى في هذه الصفحة؛ وإلا تنتقل إلى صفحتها الرئيسية. لذا فإن اللغة التي لا تترجم إلا بعض الصفحات لا توصل القرّاء أبدًا إلى صفحة 404.
- الشعار واسم الموقع في التذييل و«العودة إلى الصفحة الرئيسية» في صفحة 404 كلها تشير إلى الصفحة الرئيسية للغة الحالية.

## حزم اللغات {#language-packs}

تصف حزمة اللغة لغةً واحدة: نصوص واجهتها (في الأزرار وجدول المحتويات والتنقل بين الصفحات والإعدادات والبحث)، وخطوطها، واتجاه نصها، ونصوصها في Markdown (زر النسخ في كتل الشيفرة وعناوين الحاويات). تأتي السمة بست حزم: الصينية المبسّطة والإنجليزية واليابانية والكورية والفرنسية والعربية. تجد الصفحة حزمتها بحسب `lang`: أولًا بالرمز الكامل، ثم باللغة الأساسية (`zh-TW` تستخدم `zh`)، والإنجليزية عندما لا يتطابق أي منهما. والنصوص التي تغفلها الحزمة تكون بالإنجليزية أيضًا.

للغة لا تأتي بها السمة، اكتب حزمة لغة وضعها في `languages` في التهيئة المشتركة:

```ts
// docs/.vitepress/languages/de.ts
import { defineAkariLanguage } from "../theme/define.ts";

export default defineAkariLanguage({
  code: "de",
  messages: {
    tocOverline: "Auf dieser Seite",
    previousPage: "Zurück",
    nextPage: "Weiter",
    searchPlaceholder: "Suchen",
  },
  markdown: {
    codeCopyButton: { tooltipText: "Code kopieren", copiedText: "Kopiert" },
    container: { tipLabel: "Tipp", warningLabel: "Warnung" },
  },
});
```

```ts
// docs/config.ts
import de from "./.vitepress/languages/de.ts";

export default defineAkariConfig({
  languages: [de],
});
```

بعد ذلك، يستخدم `de-DE` و`de-AT` وأي مجلد لغة ألمانية آخر هذه الحزمة. والحزمة التي تحمل رمز حزمة مدمجة تُطبَّق فوقها: النصوص التي تكتبها تحلّ محل المدخلات المطابقة، أما `fonts` و`dir` فيُستبدلان بالكامل. ولتغيير بعض نصوص لغة واحدة في هذا الموقع فقط، يمكنك أيضًا كتابة `messages` في تهيئة تلك اللغة.

## اللغات في هذا الموقع

لكل صفحة في هذا الموقع ست نسخ: الصينية (تُقدَّم في الجذر)، والإنجليزية، واليابانية، والكورية، والفرنسية، والعربية. يبقيك تبديل اللغة في الصفحة نفسها. النسخة العربية مصمّمة من اليمين إلى اليسار، لذا يمكنك استخدامها لرؤية تخطيط RTL في السمة.

راجع [API](/ar-SA/theme/i18n/api) لجميع نصوص الواجهة ودوال اللغة، و[التفاصيل](/ar-SA/theme/i18n/details) لمعرفة كيفية اكتشاف اللغات والتبديل بينها.
