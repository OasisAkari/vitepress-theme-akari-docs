# البحث

يقع البحث على يسار شريط التطبيق. على الشاشات العريضة يكون مربع بحث فيه نص توضيحي وتلميح للاختصار؛ وعلى الشاشات الضيقة يتقلص إلى زر دائري. انقر عليه أو اضغط `⌘K` (`Ctrl K` على Windows وLinux)، فيتمدد مربع البحث إلى لوحة البحث.

## الاستخدام

| المفتاح | الإجراء |
| --- | --- |
| `⌘K` / `Ctrl K` | فتح البحث في أي صفحة |
| `↑` / `↓` | التنقل بين النتائج |
| `Enter` | فتح النتيجة الحالية |
| `Esc` | إغلاق البحث |

تُسرد النتائج بحسب الصفحة والقسم، ولكل منها مقتطف من الموضع المطابق. فتح نتيجة تخص قسمًا ينقلك بالتمرير إلى عنوانه. وفي الموقع متعدد اللغات، لا تُعاد إلا صفحات اللغة الحالية.

## الفهرس المحلي

لا تحتاج افتراضيًا إلى أي خدمة بحث خلفية. أثناء التطوير والبناء، تفحص السمة كل صفحات Markdown وتكتب `docs/public/search-index.json`: مدخل واحد لكل صفحة، ومدخل لكل عنوان من المستوى الثاني والثالث. لا يُودَع الفهرس في المستودع؛ إذ يحدّثه `npm run dev` و`npm run build` تلقائيًا.

## استخدام بحث آخر

عندما تحتاج إلى تصحيح الإملاء أو البحث الدلالي أو محتوى من خارج الموقع، انتقل إلى نقطة نهاية HTTP أو دالة JS خاصة بك:

```ts
// docs/config.ts
search: {
  backend: { type: "http", endpoint: "/api/docs/search" },
},
```

راجع [API](/ar-SA/theme/search/api) لمعرفة كيفية كتابة خدمة بحث وصيغة النتائج، و[التفاصيل](/ar-SA/theme/search/details) لحركة اللوحة وكيفية بناء الفهرس وترتيب نتائجه.
