# Vitepress Theme Akari Docs

Vitepress Theme Akari Docs is a documentation theme built with VitePress and [`@m3e/web`](https://github.com/matraic/m3e) Material 3 Expressive Web Components. Compared with [Vitepress Theme Akari Blog](https://github.com/OasisAkari/vitepress-theme-akari-blog), its layout is optimized for technical documentation.

## Requirements

- Node.js >= 22.12
- npm

## Development

```bash
npm install
npm run dev
```

The default development address is `http://localhost:5173`.

## Build and checks

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

The production output is in `docs/.vitepress/dist`.

## Configuration docs

For more configuration documentation for this theme, see [here](https://vitepress-theme-akari-docs.vercel.app/).
