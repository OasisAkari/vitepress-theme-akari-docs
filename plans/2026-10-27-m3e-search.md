# M3E Search Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 M3E VitePress 主题增加顶栏搜索框、符合 M3 设计规范的居中搜索对话框，以及本地索引/HTTP/注册式自定义搜索后端。

**Architecture:** 构建期 Vite 插件把 `docs/**/*.md` 解析成静态 `search-index.json`；客户端 `useSearch` 提供防抖、取消、键盘与状态机；`SearchTrigger` 位于 AppBar，`SearchDialog` 使用原生 modal `<dialog>` + `m3e-search-bar` / `m3e-list-action`。后端通过 local/http/registered 三种适配器统一成 `M3eSearchResult[]`。

**Tech Stack:** VitePress 2.0.0-alpha.21, Vue 3.5, @m3e/web 2.10.2, gray-matter, Vitest 5.

**Spec:** `specs/2026-10-27-m3e-search-design.md`

## Implementation Revisions (2026-10-27)

- 搜索外壳最终改为自定义原生 `<dialog>` + Web Animations API：打开把搜索按钮的 DOM 与当前计算样式克隆为 morph surface（初始帧与按钮一致），由该表面位移/缩放/插值到中心；接近落点后交叉淡入面板与内容。关闭复用当前 surface 反向缩回按钮，空间运动落定后关闭。standard/expressive 曲线由 `settings.motion` 选择。`m3e-dialog` 仅保留给文档示例。
- 关闭先淡出面板内容，再执行反向 morph；关闭期间保留 dialog 与结果状态，结束后清理并恢复焦点（优先打开前焦点，否则回到搜索按钮）。
- 移除 `m3e-search-bar` 的 clearable，避免与 dialog 关闭 X 重复。
- 输入增加 `id` / `name`；本地索引生成物 13 页、109 条目。
- 本地检索为中文子串 + 标题加权；HTTP/注册后端共用结果归一化。

```ts
function clampNumber(value: unknown, fallback: number, min: number, max: number): number {
  return typeof value === "number" && Number.isFinite(value)
    ? Math.min(max, Math.max(min, Math.round(value)))
    : fallback;
}

function normalizeSearchBackend(value: M3eSearchBackendConfig | undefined): M3eSearchBackendConfig {
  if (value?.type === "http" && value.endpoint.trim()) {
    return {
      type: "http",
      endpoint: value.endpoint.trim(),
      method: value.method === "POST" ? "POST" : "GET",
      headers: value.headers ?? {},
      credentials: value.credentials ?? "same-origin",
      queryParam: value.queryParam?.trim() || "q",
      limitParam: value.limitParam?.trim() || "limit",
    };
  }

  if (value?.type === "registered" && value.id.trim()) {
    return { type: "registered", id: value.id.trim() };
  }

  if (value?.type === "local") {
    return {
      type: "local",
      endpoint: value.endpoint?.trim() || DEFAULT_SEARCH_ENDPOINT,
    };
  }

  return { type: "local", endpoint: DEFAULT_SEARCH_ENDPOINT };
}
```

```ts
export async function buildSearchIndex(docsDir: string): Promise<SearchIndexFile> {
  const files = await collectMarkdownFiles(path.join(docsDir));
  const entries: SearchIndexEntry[] = [];
  for (const file of files) {
    const source = await readFile(file, "utf8");
    const relative = path.relative(docsDir, file).split(path.sep).join("/");
    entries.push(...parseMarkdownPage(source, relative).entries);
  }
  return { version: 1, generatedAt: new Date().toISOString(), entries };
}

export async function writeSearchIndex(docsDir: string): Promise<void> {
  const output = path.join(docsDir, "public", "search-index.json");
  await mkdir(path.dirname(output), { recursive: true });
  await writeFile(output, JSON.stringify(await buildSearchIndex(docsDir)));
}
```

- [ ] **Step 5: 实现 Vite 插件**

```ts
export function searchIndexPlugin(options: { docsDir: string }): Plugin {
  let timer: ReturnType<typeof setTimeout> | undefined;

  async function generate(): Promise<void> {
    try {
      await writeSearchIndex(options.docsDir);
    } catch (error) {
      console.error("[m3e-search] failed to build search index", error);
    }
  }

  function schedule(): void {
    clearTimeout(timer);
    timer = setTimeout(() => void generate(), 150);
  }

  return {
    name: "m3e-search-index",
    async configResolved() {
      await generate();
    },
    configureServer(server) {
      server.watcher.on("add", (file) => file.endsWith(".md") && schedule());
      server.watcher.on("change", (file) => file.endsWith(".md") && schedule());
      server.watcher.on("unlink", (file) => file.endsWith(".md") && schedule());
    },
  };
}
```
